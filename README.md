# Colby Kugel — The Engineering Hall

A Hall of Iron–inspired static portfolio built with original HTML, CSS, and inline SVG. No frameworks, paid services, API keys, or build step. Open index.html in a browser to preview it.

## Personalize before publishing

- Add your headshot as `headshot.jpg` beside `index.html`. It automatically replaces the silhouette and receives a cyan holographic treatment.
- Edit the bio and section text directly in index.html.
- Confirm every experience, title, and course. In particular, AEP is marked as an accepted opportunity because completion and dates were not provided. Add actual dates, responsibilities, and outcomes.
- Add graduation date, exact course titles, project photos and repository links, email, LinkedIn, and resume as desired. No contact addresses or links have been invented.
- The pause button controls the decorative animation; system reduced-motion preferences are also respected.

## Host free on GitHub Pages

1. Create a public GitHub repository named `YOUR-USERNAME.github.io` (substitute your real username).
2. Upload the CONTENTS of this folder, including index.html, to the repository root. Include your headshot if ready.
3. In repository Settings → Pages, choose Deploy from a branch, then main and /(root), and Save.
4. Wait for the Pages deployment to complete. Your portfolio will be available at https://YOUR-USERNAME.github.io/.
5. Commit edits or replace files in the repository to update the website.

You can also use another repository name; Pages will serve it under https://YOUR-USERNAME.github.io/REPOSITORY-NAME/. This site uses relative asset paths and works there too.

Official setup: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Files

- index.html — complete page, styling, inline illustrations, and animation control
- .nojekyll — disables unnecessary Jekyll processing on GitHub Pages
- headshot.jpg — supply your own (optional; graceful silhouette fallback)
